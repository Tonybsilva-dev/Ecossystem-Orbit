# 🎨 Checklist de UX - Nielsen's Heuristics

**Projeto:** [Nome do Projeto]
**Data:** DD/MM/AAAA

## 1. Visibilidade do Status do Sistema

- [ ] Skeleton loaders implementados para listas
- [ ] Loading states específicos por contexto
- [ ] Feedback visual em todas as ações assíncronas
- [ ] Progress indicators para operações longas

## 2. Correspondência Sistema-Mundo Real

- [ ] Linguagem natural e familiar em todas as mensagens
- [ ] Ícones e símbolos universalmente reconhecidos
- [ ] Terminologia consistente com o domínio do negócio
- [ ] Empty states com mensagens acionáveis

## 3. Controle e Liberdade do Usuário

- [ ] Botões de cancelamento em ações destrutivas
- [ ] Confirmação para ações irreversíveis
- [ ] Opção de desfazer quando aplicável
- [ ] Navegação clara (breadcrumbs, voltar)

## 4. Consistência e Padrões

- [ ] Componentes de estado padronizados (Loading, Error, Empty)
- [ ] Padrões de cores e ícones consistentes
- [ ] Mensagens de erro padronizadas
- [ ] Toast notifications com estilo consistente

## 5. Prevenção de Erros

- [ ] Validação em tempo real em formulários
- [ ] Mensagens de erro preventivas
- [ ] Desabilitação de botões quando dados inválidos
- [ ] Confirmação antes de ações críticas

## 6. Reconhecimento em vez de Lembrança

- [ ] Status visuais claros (badges, cores)
- [ ] Informações importantes sempre visíveis
- [ ] Tooltips para funcionalidades complexas
- [ ] Histórico de ações quando relevante

## 7. Flexibilidade e Eficiência

- [ ] Atalhos de teclado para ações frequentes
- [ ] Ações rápidas para usuários experientes
- [ ] Modo avançado quando aplicável
- [ ] Personalização de preferências

## 8. Estética e Design Minimalista

- [ ] Interface limpa e focada
- [ ] Informações irrelevantes removidas
- [ ] Filtros essenciais apenas
- [ ] Hierarquia visual clara

## 9. Ajudar Usuários a Reconhecer e Recuperar de Erros

- [ ] Mensagens de erro em linguagem simples
- [ ] Indicação precisa do problema
- [ ] Sugestão de solução
- [ ] Botão de retry quando aplicável

## 10. Ajuda e Documentação

- [ ] Tooltips contextuais
- [ ] Ajuda inline quando necessário
- [ ] Documentação acessível
- [ ] Tutorial/onboarding para novos usuários

## 11. Acessibilidade (WCAG 2.1 AA)

- [ ] Skip link implementado
- [ ] Estrutura semântica (header, main, footer, sections)
- [ ] Aria-labels descritivos
- [ ] Navegação por teclado funcional
- [ ] Z-index hierarquia clara
