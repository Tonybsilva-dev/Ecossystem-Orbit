# 🤖 Checklist de AI-AEO - Answer Engine Optimization

**Projeto:** [Nome do Projeto]
**Data:** DD/MM/AAAA

## 1. Estrutura de Conteúdo

- [ ] Resposta direta no início do conteúdo
- [ ] Conteúdo estruturado hierarquicamente
- [ ] FAQs estruturados implementados
- [ ] Listas numeradas e com marcadores claros
- [ ] Tabelas para comparações quando aplicável
- [ ] Introdução e conclusão bem definidas

## 2. Dados Estruturados (Schema.org)

- [ ] FAQPage Schema implementado
- [ ] HowTo Schema para tutoriais
- [ ] Article Schema com informações de autoridade
- [ ] Informações de autor e publisher completas
- [ ] Data de publicação e atualização

## 3. Autoridade (E-E-A-T)

- [ ] Informações do autor visíveis
- [ ] Credenciais e experiência demonstradas
- [ ] Citações e referências estruturadas
- [ ] Links para fontes confiáveis
- [ ] Afiliações e organizações mencionadas

## 4. Formato de Resposta

- [ ] Respostas em formato conversacional
- [ ] Conteúdo completo e detalhado
- [ ] Contexto adicional fornecido
- [ ] Exemplos práticos incluídos
- [ ] Glossário para termos técnicos

## 5. Citações e Referências

- [ ] Referências estruturadas
- [ ] Links para fontes autoritárias
- [ ] Citações com links e fontes
- [ ] Dados com fontes claras

## 6. Monitoramento

- [ ] Rastreamento de citações implementado
- [ ] Analytics configurado para AEO
- [ ] Métricas de referências de assistentes de IA
